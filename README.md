# 👤 React Profile Card

A simple and beginner-friendly Profile Card application built using **React.js**. This project demonstrates the fundamentals of React components, JSX, CSS styling, and component imports.

## ✨ Features

- Displays a profile card using a reusable React component.
- Simple and clean user interface.
- Custom styling using CSS.
- Component-based project structure.
- Built with Vite for a fast development experience.

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Folder

```bash
cd second-project
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173/
```
